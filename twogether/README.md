# TwoTogether Android

Cute private-couple app starter. Includes login/signup screens (demo-only), mood selector, home dashboard, and feature cards.

## Build APK
GitHub Actions workflow `.github/workflows/twogether-apk.yml` builds a debug APK on pushes to the `twogether/**` project.

## Important
This starter currently uses demo authentication and placeholder feature screens. Firebase Auth, Firestore chat, Storage uploads, push notifications, WebRTC calling, stories and multiplayer require Firebase project configuration and additional implementation. Do not enter real passwords into demo mode.

Download APK from the GitHub Actions run's Artifacts section when the workflow finishes.
